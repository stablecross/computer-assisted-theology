# stablecross fonts

The stablecross font exists for the two glyphs "lefty" <img src="lefty.svg" alt="◧" height="16"> and "righty" <img src="righty.svg" alt="◨" height="16">.

"lefty" is mapped to \ and ◧ (U+25E7)

"righty" is mapped to | and ◨ (U+25E8)

"lefty" and "righty" were designed with two criteria:
1. They had to be unique such that no reader might associate a pre-defined meaning to them.
2. They had to be symmetric so that one could be easily converted to the other.

Originally, only \ and | were defined. Later, AI (Claude) suggested using Unicode ◧ and ◨ in a document such that if the stablecross font was not available, glyphs that partially matched the design criteria would still be displayed.

lefty.graffle contains the original drawing of lefty.
